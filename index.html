Playfair Cipher

Encrypt or decrypt using a 5 × 5 key matrix. I and J are treated as the same letter.

CIPHERTEXT

5 × 5 Playfair Key Matrix

The matrix is automatically generated from your keyword. Duplicate letters are removed and J is merged with I.

Same row: move right for encryption.
Same column: move down for encryption.
Rectangle: exchange the columns of the two letters. Decryption reverses the row and column directions.

Hill Cipher

Matrix-based encryption using modular arithmetic. Enter a 2 × 2 key matrix with an inverse modulo 26.

Default key: [[3, 3], [2, 5]].
A = 0, B = 1, ..., Z = 25.
The determinant must be relatively prime to 26.

CIPHERTEXT

How Hill Cipher Works

Encryption: C = K × P (mod 26)

Decryption: P = K⁻¹ × C (mod 26)

For a 2 × 2 key, letters are processed in pairs. If the plaintext contains an odd number of letters, X is appended before encryption.
The calculation steps will appear here after encryption.
