Playfair Cipher

Encrypt and decrypt messages using a 5 × 5 key matrix. I and J are treated as the same letter.

CIPHERTEXT

5 × 5 Playfair Key Matrix

The matrix is generated automatically from your keyword. Duplicate letters are removed and J is merged with I.

Encryption rules
Same row: replace each letter with the letter to its right.
Same column: replace each letter with the letter below it.
Rectangle: replace each letter with the letter in the same row and the other letter's column.

Decryption reverses the row and column directions. Repeated letters in a pair are separated using X.

Hill Cipher

Matrix-based encryption using modular arithmetic. Select a 2 × 2 or 3 × 3 key matrix.

A = 0, B = 1, ..., Z = 25.
The determinant must be relatively prime to 26 for the matrix to have an inverse modulo 26.
All matrix values are automatically reduced modulo 26.

CIPHERTEXT

How Hill Cipher Works

Encryption formula
C = K × P (mod 26)

Decryption formula
P = K⁻¹ × C (mod 26)

For a 2 × 2 key, letters are processed in blocks of 2.
For a 3 × 3 key, letters are processed in blocks of 3.

If the message length is not divisible by the matrix size, X is appended to complete the final block.
Matrix calculations will appear here after encryption or decryption.
